Taruh logo sekolah di folder ini dengan nama: logo.png

Contoh:
  img/logo.png

Kalau file ini ada, logo otomatis muncul di halaman depan.
Kalau tidak ada, halaman depan tetap jalan tanpa logo.

Cara lain tanpa menyentuh file:
  Buka Panel Operator (⚙) -> "Logo sekolah di halaman depan" -> Pilih gambar.
  Logo akan tersimpan di browser perangkat itu.
